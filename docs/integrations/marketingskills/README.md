# MarketingSkills integration map — Campaign Frameworks Atlas

Upstream: https://github.com/coreyhaines31/marketingskills (MIT; retain licence and attribution when redistributing).

The ten Adobe Campaign Classic v8 framework build sheets and toolkit remain unchanged. MarketingSkills are supplementary planning and measurement references only.

## Candidate mappings
- email-sequence, churn-prevention → cart abandonment and lifecycle strategy
- ab-test-setup → test-loop and experiment design
- analytics-tracking → attribution ETL measurement specification
- customer-research → audience/problem validation
- revops → lead scoring and nurture lifecycle
- seo-audit, ai-seo, content-strategy → portfolio/toolkit discoverability

## Guardrails
All examples and KPI values remain explicitly synthetic/simulated. Never represent sample configurations as production-ready or client-validated. No skill can run Campaign workflows, query production data, send deliveries, change consent, or activate audiences. Keep privacy, consent, typology, approval, and operational checks intact.

Import only reviewed skills, pinned to an upstream commit, in a separate namespace. Preserve all existing framework files. Run repository tests and validate links after changes.
